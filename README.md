# WISAA Creative Motion

An Arabic commercial creative composition for a travel-product campaign.

## What it demonstrates

- Product-led short-form visual storytelling
- Reusable Remotion scenes and timing
- Arabic typography, color direction, and message hierarchy
- Separation of composition code from source media and generated audio

## Stack

Remotion · React · TypeScript · Tailwind CSS

## Run locally

```bash
npm install
npm run lint
npm run dev
```

Generated voice, music, product images, and rendered previews are intentionally excluded from this public code snapshot. Confirm asset rights before redistribution.
